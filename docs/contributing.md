# 🤝 Bidra til Trevl

Takk for at du vurderer å bidra til Trevl! Dette dokumentet gir retningslinjer og instruksjoner for bidrag.

## Kom i gang

1. Fork repositoriet
2. Lag en ny branch for din funksjonalitet/fiks:
```bash
git checkout -b feature/din-funksjonalitet
```

## Utviklingsretningslinjer

### Kodestil
- Bruk TypeScript for all ny kode
- Følg eksisterende kodestil og formatering
- Bruk ESLint og Prettier for å sikre konsistent kode
- Skriv beskrivende commit-meldinger

### Komponenter
- Hold komponenter små og fokuserte
- Bruk TypeScript-props
- Følg React beste praksis
- Dokumenter komplekse komponenter

### Internasjonalisering (i18n)
- Legg til oversettelser for alle støttede språk
- Bruk oversettelsesnøkler konsekvent
- Test alle språkversjoner

## Pull Requests

1. Oppdater dokumentasjonen hvis nødvendig
2. Sørg for at alle tester passerer
3. Beskriv endringene dine detaljert
4. Link til relevante issues

## Rapportere Problemer

Når du rapporterer et problem, inkluder:
- Detaljert beskrivelse
- Steg for å reprodusere
- Forventet vs. faktisk oppførsel
- Skjermbilder hvis relevant

## Kodeoversikt

For større endringer, diskuter først med vedlikeholderne ved å:
1. Åpne en issue
2. Beskrive den planlagte endringen
3. Få tilbakemelding før implementering

## Teststrategi

- Skriv tester for ny funksjonalitet
- Oppdater eksisterende tester ved behov
- Test på tvers av nettlesere
- Test responsivt design

## Sikkerhet

- Rapporter sikkerhetsproblemer direkte til vedlikeholderne
- Ikke commit sensitive data
- Følg beste praksis for sikkerhet

## Lisens

Ved å bidra til Trevl, godtar du at ditt bidrag vil bli lisensiert under samme vilkår som prosjektet.
