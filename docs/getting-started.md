# 🚀 Kom i gang med Trevl

## Forutsetninger
- Node.js (v18 eller nyere)
- npm eller yarn
- Git

## Installasjon

1. Klon prosjektet:
```bash
git clone https://github.com/Marcus-Kodehode/trevl.git
cd trevl
```

2. Installer avhengigheter:
```bash
npm install
# eller
yarn install
```

3. Start utviklingsserveren:
```bash
npm run dev
# eller
yarn dev
```

Åpne [http://localhost:3000](http://localhost:3000) i nettleseren din for å se applikasjonen.

## Bygg for produksjon

1. Lag en produksjonsbygg:
```bash
npm run build
# eller
yarn build
```

2. Start produksjonsserveren:
```bash
npm start
# eller
yarn start
```

## Tilgjengelige Scripts

- `npm run dev` - Start utviklingsserver
- `npm run build` - Lag produksjonsbygg
- `npm start` - Start produksjonsserver
- `npm run lint` - Kjør ESLint for kodekvalitet

## Teknologier

- Next.js
- React
- TypeScript
- Tailwind CSS
- Vercel Analytics

## Språkstøtte

Trevl støtter følgende språk:
- Norsk (no)
- Engelsk (en)
- Spansk (es)
- Kinesisk (Tradisjonell) (zh-Hant)

For å legge til eller redigere oversettelser, se i `i18n/messages/` mappen.
